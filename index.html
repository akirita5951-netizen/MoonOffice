About Moon Office

Moon Office is an asymmetrical horror game on Roblox. Play as a survivor, support, or killer. The game is currently in development and is planned for release in 2027.

What to expect

Multiplayer

Team up with friends and other players while following the community guidelines.

Lightweight design

We’re aiming for a lightweight, optimized experience so more players can enjoy the game smoothly.

Technical support

We’ll offer technical support to help resolve any issues you encounter.

Collaborations

Security systems

We’re building safeguards to help protect the game from exploits and cheating.

We’re always working to improve the game and make your experience better.
